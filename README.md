# Spray Engineering Calculator

현재 1단계로 계산기 선택 화면과 노즐 분사량 계산기를 제공합니다.

- 기준점 P1, P2 두 개
- 카탈로그 값을 반응형 HTML 표로 재구성하고 노즐 2번 행과 2·3 bar 열을 강조
- 압력값 영역은 주황색, 노즐 번호 영역은 초록색으로 안내 문구와 동일하게 구분
- 입력 조건과 계산 결과 영역의 제목 글씨 확대
- 압력 기준과 유량 기준을 선택하여 액체와 공기를 정방향·역방향 계산
- 선택한 계산 기준, 결과와 목표점을 그래프 및 PDF 리포트에 자동 반영
- P1, P2를 항상 적용하며 입력값은 소수점 둘째 자리까지 표시
- 모든 압력·유량을 0.00으로 바꾸는 입력 조건 초기화 버튼과 좌우 분리형 작업 화면
- 일류체 노즐 (액체), 이류체 노즐 (액체 + 에어) 선택
- 액체: 두 기준점에서 K = Q/√P를 구해 평균 적용 (일류체 LPM, 이류체 L/H)
- 공기: 첨부 식 Q = (237.6/1.2) × (πD²/4) × C × (P/0.980665 + 1.033) / √(t+273)을 사용
- 공기 기준점에서 C를 역산해 평균 적용하며, 구경 D(mm)와 온도 t(°C)는 기준점과 목표 조건에 공통 적용
- 공기 유량 표시는 NL/min이며 첨부 식의 밀도 1.2 kg/m³ 기준을 따릅니다. 다른 카탈로그 기준 상태의 유량은 환산 후 입력해야 합니다.
- 액체 K와 공기 C, 각각의 압력-유량 곡선 및 기준점을 2페이지 이류체 PDF에 포함
- 역산 결과가 음의 게이지압이 되는 공기 목표 유량은 범위 안내를 표시하고 리포트 다운로드를 비활성화
- 압력-유량 특성 곡선
- Spraying Systems Co. 로고가 포함된 PDF 리포트 다운로드
- 계산기 02, 03은 다음 단계에서 추가 예정

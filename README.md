# Spray Engineering Calculator

2026-09-12 업데이트. `NozzleWeb.py` 안에 계산식, 화면, 참고표와 SLIT BLOWER 원본 이미지가 포함되어 있습니다.

## 계산기 구성

1. 노즐 분사량 계산기 — 기존 기능
2. 물 기준 노즐 유량 계산기 — 유량·압력·구경 역산, 유속, 구경·유속에 따른 유량
3. 압축 공기량 계산기 — 솔리드 노즐 및 슬릿 등가 구경
4. SLIT BLOWER 풍량 계산기 — 풍량, 접속구 수량, 용도별 참고표
5. 배관 선정 계산기 — AIR 내경·유속, WATER 내경·유속·유량·압력손실
6. 밀도·비중별 유량 계산기 — 질량·부피 환산, 비중 보정, 혼합물 밀도
7. SprayLayout Pro · 노즐 배치 계산기 — Tony 원본 HTML
8. 노즐 충격력·펌프 계산기 — Ben 원본 HTML

7·8번은 선택한 페이지에서만 원본 HTML을 불러옵니다. 각 계산기의 기능과 디자인을 유지하며, PDF 버튼은 브라우저 인쇄 창을 엽니다. 인쇄 대상으로 PDF 저장을 선택하세요. 8번 페이지 아래의 단독 실행용 HTML 다운로드로 해당 원본 파일도 저장할 수 있습니다. 추가 파일 업로드 없이 NozzleWeb.py에 모두 포함되어 있습니다.

2~6번 계산기는 입력 조건, 즉시 계산 결과, 변화 그래프, 계산식 보기, 그래프를 포함한 PDF 다운로드를 제공합니다. 입력·결과·참고표·그래프 눈금은 소수점 두 자리로 표시하며 계산 내부 정밀도는 유지합니다. 새 그래프와 참고표는 다크 모드에서도 밝은 배경을 사용합니다.

## 실행

Python 3.10 이상에서 두 명령을 실행합니다.

```sh
python -m pip install -r requirements.txt
python -m streamlit run NozzleWeb.py
```

기존 Streamlit 저장소에는 `NozzleWeb.py`와 `requirements.txt`를 같은 위치에 적용하면 됩니다.

## 원본과 단위

- 기반 소스: 제공된 GitHub 저장 페이지의 커밋 `3375f53349b8c82e5045e567a66c4d2d39bea6eb`.
- 2~6번의 원본은 첨부 순서대로 `배관 선정 계산식_AIR_WATER.xls`, `노즐 구경에 대한 압축 공기량 계산식.xls`, `노즐 구경에 대한 물기준 유량 계산식.xls`, `SLIT BLOWER 풍량계산식.xlsx`, `밀도 비중별 유량 계산식.xls`입니다.
- 원본 예시값과 일치하도록 3.14, 0.785, 273, 9.8 등의 원식 상수를 유지했습니다. 기본 입력값은 원본 설정값입니다.
- 압축공기 원본의 셀 제목은 bar, 텍스트 도형의 수식 설명은 kgf/cm²입니다. 3번은 수식 설명에 따라 kgf/cm²를 기본으로 사용하며, bar를 선택하면 kgf/cm²로 환산합니다. 밀도 1.2 kg/m³ 기준 체적유량입니다.
- 2번 AIR의 입력 유량은 사용자 확인에 따라 운전 게이지압에서의 실제 체적유량입니다. 압력비로 나누는 중복 보정을 제거하고 `Q=A×v`로 내경·유속을 계산합니다. 결과의 배관 내 통과 유량은 입력 유량과 같습니다. 이는 원본 엑셀의 압력비 보정 방식에서 변경된 부분입니다.
- WATER 배관 계산 및 4번 물 기준 노즐 계산의 수식과 결과는 유지했습니다.
- 압축공기의 슬릿 지수는 등가 구경을 구할 때 적용되며, 공기 유량계수와 별개입니다. 슬릿 모드에서는 계산된 등가 구경을 공기량 계산에 직접 연결합니다.
- SLIT BLOWER 이미지의 접속구 용량은 25A: 2.3, 40A: 4.8, 50A: 7.6 m³/min입니다. 필요한 수량은 풍량을 접속구 용량으로 나누어 올림합니다. 이미지 예제의 서로 일치하지 않는 풍속·풍량·수량은 그대로 복사하지 않았습니다.
- 비중 보정은 액체→물일 때 `Qwater = Qliquid × √SG`, 반대 방향은 `Qliquid = Qwater / √SG`입니다. 이는 원본 셀의 괄호를 포함한 수식과 일치합니다.
- 배관 부속품 등가길이 표의 원본 빈 값은 제공되지 않은 값으로 표시합니다. 호칭구경은 실제 배관 내경과 다릅니다.

## 확인한 사항

- 5개 파일의 셀 값·수식·도형 텍스트와 삽입 이미지를 확인했습니다.
- 주요 출력값을 엑셀 저장값과 비교했습니다.
- 물 유량/압력/구경 및 비중 보정의 역산, 접속구 수량 경계값, 0으로 나누는 입력을 검사했습니다.
- 기존 1번 계산기 및 추가 18개 계산 항목의 화면 전환·계산·초기화를 검사했습니다.
- 브라우저에서 5개 추가 계산기의 PDF 다운로드와 화면을 확인했습니다.
- 모바일 폭 390px에서 화면의 가로 넘침이 없는 것을 확인했습니다.

검증 환경: Streamlit 1.63.0, ReportLab 4.5.1. 실제 배관·노즐 선정에는 적용 조건과 현장 손실을 함께 검토하세요.

7번은 원본 HTML 그대로 전체 화면 폭으로 표시합니다. 원본 외부에는 계산기 목록으로 돌아가는 버튼만 표시합니다. 원본의 계산 로직·입력 기능·배열·내용을 유지하며, 화면 높이를 본문에 맞추는 연결 부분을 다시 구성했습니다. Streamlit 1.63 이상이 필요하므로 requirements.txt도 함께 적용하세요.

7번 하단 정보 바는 원본 문구를 유지하면서 고정 위치를 해제했습니다. 본문 다음에 배치되어 내용을 가리지 않으며, 좁은 화면에서는 줄바꿈됩니다.

7번 재구성 검증: 원본과 15가지 조건의 결과 일치, 이미지 업로드, 새로고침, PDF 인쇄 호출, 목록 복귀 및 재진입을 확인했습니다. 화면 폭 1440 → 390 → 1440px 변경 시 본문에 맞춰 높이가 늘어나고 다시 줄어드는 것을 확인했습니다.
